# CustomerDNA AI - ML EDA Layer

This folder contains the visual exploration and model-evaluation layer for the
Client 1 ML phase.

Purpose:
- Explore ML-ready datasets generated from the `serving` schema
- Produce exportable plots for the PFE report and jury presentation
- Summarize model behavior, strengths, weaknesses, and risks

Structure:
- `scripts/`: reusable EDA and plotting scripts
- `reports/`: markdown summaries generated by EDA scripts
- `plots/`: exported PNG charts organized by use case

Initial implementation:
- `run_churn_eda.py`: churn-specific ML EDA and evaluation plots

Planned next implementations:
- segmentation
- ltv
- persona
- marketing_recommendation
