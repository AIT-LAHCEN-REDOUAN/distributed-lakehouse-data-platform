NOTES
============================================================

- Trino worker endpoints on VM1 and VM3 are technical HTTP endpoints, not user UIs.
- Kafka broker ports are service endpoints, not web pages.
- The main Trino UI is only on VM2 through the gateway on `http://10.10.252.12:8088/ui/` or `https://10.10.252.12:8443/ui/`.
- The control plane local entry ports can be remapped if a port is already busy. Check `control_plane_pc\runtime\compose.generated.env` for the active values.
- VM1, VM2, and VM3 runtime service data can be mounted on LUKS-encrypted storage under `/mnt/customerdna_secure` when `setup_encrypted_storage_vmX.sh` is used.
