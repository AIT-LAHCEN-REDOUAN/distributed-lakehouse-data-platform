# Report Workspace Workflow

This file keeps the report folder operationally clear.

## Main rule

`PFE_report/` is the standalone academic writing and compilation space.

## Writing order

1. front matter
2. Chapter 1
3. Chapter 2
4. Chapter 3
5. Chapter 4
6. Chapter 5
7. Chapter 6
8. Chapter 7
9. Chapter 8
10. Chapter 9
11. Chapter 10
12. references
13. appendices
14. final packaging

## Evidence rule

Store report-facing screenshots, logs, validation notes, figures, and tables inside this folder only.

## Compilation rule

The report must compile from this folder alone in TeXstudio.

## External reference rule

The `project_requirements/` folder and other engineering folders are reference sources for the writing assistant, but the report workspace itself must remain understandable and usable on its own.
