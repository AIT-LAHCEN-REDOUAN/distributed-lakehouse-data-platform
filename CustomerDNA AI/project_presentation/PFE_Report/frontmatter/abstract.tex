\frontchapter{Abstract}
Modern organizations increasingly rely on data produced from multiple heterogeneous sources, including transactional systems, e-commerce platforms, behavioral event streams, and customer profile datasets. However, transforming these raw inputs into reliable, governed, and analytics-ready data products requires a structured data engineering platform capable of ingestion, storage, distributed processing, validation, orchestration, and monitoring.

This final year project presents \textbf{CustomerDNA AI -- Distributed Customer Data Lakehouse Platform}, developed as the customer-data engineering foundation of the global \textbf{AdOptimizer} project. The implemented Customer Data Platform serves as a distributed lakehouse that centralizes heterogeneous customer data, preserves replayable raw history, produces governed analytical tables, and supplies trusted data foundations for future machine-learning and artificial-intelligence products. It integrates Apache Kafka for ingestion, Hadoop HDFS for distributed bronze storage, Apache Spark for multi-worker processing, Apache Iceberg and Hive Metastore for lakehouse table management, Trino for distributed SQL access, dbt-Spark for governed transformations, Great Expectations for auditable quality validation, Apache Airflow for orchestration, and Prometheus with Grafana for observability.

The implemented Client~1 scope combines Bank Marketing, Online Shoppers Purchasing Intention, and Online Retail~II data to cover campaign response, digital intent, and transactional behavior. The platform is deployed as a distributed data plane across three virtual machines with a centralized control plane on the local PC. It produces raw and curated Iceberg tables, Great Expectations validation artifacts and Data Docs, orchestrated run history, and operational dashboards. The result is a Customer~360-ready analytical foundation; machine-learning models remain downstream future consumers rather than the core contribution of this PFE.
