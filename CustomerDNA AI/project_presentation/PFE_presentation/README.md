# AdOptimizer CDP - Future Defense Presentation Workspace

This folder must be treated as a **standalone presentation workspace**.

It should not depend on the internal structure of `PFE_report/`.

The presentation should be built only after the report content is stabilized, but when it is built, it should contain its own:

- storyline,
- speaker notes,
- visual assets,
- screenshots,
- demo flow,
- and export-ready delivery files.

## Folder meaning

- `00_master/`
  - presentation-wide rules and structure
- `00_planning/`
  - presentation strategy and timing plan
- `01_storyline/`
  - defense narrative and slide sequence
- `02_slide_drafts/`
  - slide-by-slide working drafts
- `03_visual_assets/`
  - reused figures, diagrams, and screenshots
- `04_demo_flow/`
  - live demo sequence, fallback flow, and jury-safe demo notes
- `05_speaker_notes/`
  - presenter-facing speaking support
- `90_assets/`
  - presentation-only assets such as diagrams, icons, and figures
- `91_evidence/`
  - screenshots and demo evidence selected for the jury
- `92_export_package/`
  - packaged export-ready presentation bundle
- `99_final_delivery/`
  - export-ready final deck
