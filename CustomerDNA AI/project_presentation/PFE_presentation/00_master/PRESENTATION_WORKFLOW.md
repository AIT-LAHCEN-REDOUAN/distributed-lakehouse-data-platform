# Presentation Workspace Workflow

This file defines the basic workflow for the future defense deck.

## Main rule

`PFE_presentation/` is a standalone workspace dedicated to the oral defense.

## Recommended build order

1. define the jury storyline,
2. decide the slide sequence,
3. collect approved report figures,
4. prepare simplified architecture visuals,
5. prepare speaker notes,
6. prepare the live demo sequence,
7. package the final deck.

## Dependency rule

The presentation can reuse ideas from the report, but the folder itself must remain usable independently once built.
