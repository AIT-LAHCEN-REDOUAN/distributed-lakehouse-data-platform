# CustomerDNA AI - Generated Artifacts

This folder is reserved for runtime-generated outputs so the source tree stays clean and easy to explain.

## Purpose

The project separates:

- source code under `CustomerDNA AI/src/`
- generated artifacts under `CustomerDNA AI/artifacts/`

This keeps implementation logic, orchestration code, and monitoring configuration easier to review during development and during the PFE defense.

## Current Intended Structure

- `client_1/ml/`
  Contains ML snapshots, processed datasets, model binaries, metadata, experiment reports, and ML-focused EDA outputs.

- `client_1/elt_eda/`
  Contains dataset-level EDA outputs generated from the warehouse-backed ELT analysis scripts.

## Important Note

Files inside this folder are generated artifacts, not hand-maintained source code.
They may be deleted and regenerated by rerunning the corresponding pipelines or analysis scripts.
