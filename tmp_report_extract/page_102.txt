B.3 Cross-Cutting Deployment Properties
Property Compose-derived implementation
Network organization Data-plane services use host networking on the Linux VMs. The local control
plane uses its Compose network, while a Caddy gateway publishes the
selected Airflow, Prometheus, Grafana, and Kafka UI interfaces.
Persistent state Named volumes retain control-plane PostgreSQL, Prometheus, Grafana, and
gateway state. VM definitions mount dedicated runtime directories for Kafka,
HDFS, Spark events, Hive PostgreSQL, Trino, Kerberos, and audit data.
Identity and protected
access
VM definitions mount the Kerberos client configuration and service-specific
keytab locations. HDFS mounts TLS configuration, while Caddy gateways
protect the Trino and control-plane browser paths.
Startup dependencies
and health
Compose dependencies establish key startup relationships around
PostgreSQL, Kerberos, HDFS, Hive, Spark, Trino, Prometheus, and Airflow.
Health checks are declared for critical stateful and entry-point services.
Observability cAdvisor runs on VM1, VM2, and VM3. The local Prometheus and Grafana
services consume infrastructure, PostgreSQL, and pipeline-exporter signals.
Controlled
configuration
Images, versions, addresses, ports, runtime directories, and credentials are
parameterized through environment variables. The report retains the
architecture and role mapping while excluding secret values.
