VII.9 Security Boundaries and Remaining Limits
The implemented security layer provides a meaningful distributed-platform hardening
baseline; it does not constitute a finished enterprise security program.
The current implementation can validly claim:
•Kerberos-secured Hadoop runtime;
•SPNEGO-protected HDFS browser access;
•TLS-protected browser-facing endpoints;
•authenticated Trino access;
•SSH-based remote Spark submission;
