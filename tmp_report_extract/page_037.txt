III.3.1 Event Ingestion and Distributed Bronze Storage
Kafka was retained as the ingestion backbone because its partitioned-topic model maps
directly to the project’s dataset-specific transport and three-broker topology [7]. RabbitMQ
providesmaturequeueandstreamabstractions,whilePulsarprovidesdistributedmessaging
with multiple subscription models [12, 9]. Both are credible alternatives, but adopting
either would have introduced a different operational model without improving the required
Kafka-to-HDFS replay path already implemented in the platform.
HDFS was selected for the bronze landing zone because its NameNode/DataNode archi-
tecture and configurable block replication make distributed persistence directly observable
across the three VMs [3]. Local or shared folders would not demonstrate distributed storage,
while object storage would provide a different access abstraction and would weaken the
intended Hadoop-centered deployment demonstration. HDFS therefore serves both an
engineering purpose—replayable raw persistence—and an architectural purpose by proving
that bronze data is physically managed by a distributed file system.
III.3.2 Lakehouse Tables, Metadata, and File Format
Apache Iceberg manages the structured raw and curated lakehouse tables, Hive Metastore
centralizes their discoverable metadata, and Parquet provides the underlying columnar file
representation [6, 4, 8]. This separation is important: Parquet defines how analytical data
is stored in files, Iceberg adds table-level metadata and evolution capabilities, and Hive
Metastore exposes shared catalog definitions to compatible engines.
Delta Lake and Apache Hudi were considered as alternative lakehouse table technologies
[16, 5]. Iceberg was retained because the implemented project required a neutral table layer
shared by Spark and Trino, with explicit schema and partition evolution rather than a
platform-specific managed environment. The choice also aligns with the report’s objective
of making the relationship between physical files, table metadata, and the external catalog
academically visible.
